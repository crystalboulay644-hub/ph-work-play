# PH WORK — game launch link

This small GitHub Pages site points visitors to the owner's current Mac-hosted
Dead Signal game. The launch address stays the same across tunnel restarts.
The Mac must be powered on, logged in and connected. The gameplay address itself
is a temporary Cloudflare Tunnel address.

This repository contains only the launch page and its current public destination.
Game models, textures, sounds, server code and credentials are not stored here.
